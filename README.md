# claude-code-dan — 脆弱性発見の昇段審査用コードセット

このリポジトリは、Claude Code の脆弱性発見能力を 10 段階（初段〜十段）で測るために用意した、
**意図的に脆弱性を埋め込んだ学習用コード**です。各レベルは小さな自己完結アプリで、
現実のコードに見えるようノイズとデコイ（危なく見えるが実際は安全な実装）を混ぜています。

## 警告

- このコードは **教育・計測目的の意図的な脆弱コード** です。本番環境・インターネットに公開しないでください。
- すべてのアプリは `127.0.0.1`（ループバック）にのみバインドします。外部ネットワークへは公開しません。
- 実在のサービスやシステムを攻撃する目的で使わないでください。
- 想定読者は、自分のローカル環境で検証するセキュリティ学習者・実務者です。

## 構成

| パス | 内容 |
|:--|:--|
| `levels/L01`〜`levels/L10` | 審査対象のアプリ（初段〜十段）。解答は含みません |
| `harness/` | Claude Code に監査させて結果を採点するランナーと採点スクリプト |
| `poc/` | 各レベルの脆弱性が実在することを示すローカル再現テスト |
| `answer-key/levels.json` | 解答キー（各レベルの脆弱性の位置・CWE・デコイ）。`harness/scorer.py` が参照します |
| `calibration/` | 九段・十段を作り直したキャリブレーションの全履歴（各回のプローブ結果と、作り直し候補3件のコードとPoC） |
| `LICENSE` | MIT License |

解答キーは `answer-key/levels.json` にあります。自分で解きたい場合は先に開かないでください。
計測時は解答キーを `levels/` の外に置き、監査対象として複製するのは `levels/<Lxx>` だけなので、監査されるモデルからは読めません。

## 動かし方（ローカル検証）

各レベルは単体で起動できます。

```bash
# 例：初段のアプリをローカルで起動します（127.0.0.1 固定）
cd levels/L01
python3 app.py
```

```bash
# 例：脆弱性の実在を再現テストで確認します（ローカルのみ）
python3 poc/L01_poc.py
```

## 段位の設計方針

- 初段〜三段：1 ファイル内で完結する古典的な 1 行級の欠陥
- 四段〜六段：ファイルや層をまたいでデータを追わないと見えない欠陥
- 七段〜八段：状態・時間・プロトコルに起因する欠陥
- 九段〜十段：個々は無害な挙動の組み合わせ、コンポーネント間の解釈差、暗号の誤用など、
  明示的に監査しても気付きにくい欠陥
